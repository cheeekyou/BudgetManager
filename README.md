# 💰 BudgetManagerBot

Telegram-бот для учёта личного бюджета. Поддерживает 5 категорий расходов, три стиля общения, ежедневные отчёты и историю.

## 📌 Возможности

- 5 категорий расходов: 🏠 постоянные, 🛍️ временные, 🚨 непредвиденные, 📝 плановые, ☕ ежедневные покупки
- Умный ввод сумм: `30к`, `30 тыс`, `30 тысяч`, `234.60` → округление вверх
- Три стиля общения: официальный, разговорный, с юмором
- Ежедневная проверка с пересчётом дневного лимита
- Общий фонд, история по месяцам, финансовые советы
- Данные хранятся в SQLite

## 🚀 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу (при первом запуске — настройка бюджета) |
| `/add`   | Добавить расход (категория, сумма, описание) |
| `/status` | Показать текущее состояние: остаток, лимит, категории |
| `/fund`   | Показать общий фонд (все сбережения) |
| `/history` | История по месяцам (сколько сэкономлено) |
| `/daily`  | Ежедневная проверка (без трат / были траты / пропустить) |
| `/style`  | Сменить стиль общения |
| `/cancel` | Отменить текущее действие |

## 🛠️ Установка и запуск

1. **Клонируйте репозиторий**
git clone https://github.com/cheeekyou/BudgetManager.git
cd BudgetManager

text

2. **Установите зависимости**
pip install -r requirements.txt

text
(если файла `requirements.txt` нет — установите вручную: `aiogram`, `aiosqlite`, `python-dotenv`)

3. **Создайте файл `.env`** и добавьте токен бота:
BOT_TOKEN=ваш_токен_от_BotFather

text

4. **Запустите бота**
python telegram_bot.py

text

## 🧪 Как получить токен

1. Напишите [@BotFather](https://t.me/botfather) в Telegram.
2. Отправьте `/newbot` и следуйте инструкциям.
3. Скопируйте полученный токен в файл `.env`.

## 📁 Структура проекта

- `telegram_bot.py` — основной код бота
- `budget_bot.db` — база данных SQLite (создаётся автоматически)
- `humor_phrases.json` — файл с шутками (необязательно)
- `.env` — токен бота (не публикуется на GitHub)
